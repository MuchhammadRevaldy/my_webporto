# Antigravity Portfolio - Revaldy Sandy Aji

A high-performance, physics-based portfolio website built with React, Tailwind CSS, Framer Motion, and React Three Fiber.

## 🚀 Deployment to Vercel

This project is optimized for deployment on [Vercel](https://vercel.com).

### Steps:

1.  **Push to GitHub:**
    Ensure this project is pushed to a GitHub repository.
    ```bash
    git init
    git add .
    git commit -m "Initial commit"
    # git remote add origin <your-repo-url>
    # git push -u origin main
    ```

2.  **Import to Vercel:**
    - Go to your Vercel Dashboard.
    - Click **"Add New..."** -> **"Project"**.
    - Import your GitHub repository.

3.  **Configure Project:**
    - **Framework Preset:** Vite
    - **Root Directory:** `./` (default)
    - **Build Command:** `npm run build` (default)
    - **Output Directory:** `dist` (default)
    - **Install Command:** `npm install` (default)

4.  **Deploy:**
    Click **"Deploy"**. Vercel will detect the settings automatically.

## 🛠 Tech Stack

-   **Framework:** React (Vite)
-   **Styling:** Tailwind CSS
-   **Animations:** Framer Motion
-   **3D/Physics:** React Three Fiber, Maath
-   **Scrolling:** Lenis

## 🏃‍♂️ Local Development

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run development server:
    ```bash
    npm run dev
    ```

3.  Open `http://localhost:5173`
